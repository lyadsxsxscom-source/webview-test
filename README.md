# قالب تطبيق أندرويد يغلّف موقع (WebView)

بيحوّل أي موقع HTTPS لتطبيق أندرويد: أيقونة وشاشة بداية، والموقع بيفتح داخل التطبيق، وصفحة "ما في اتصال" مع زر إعادة المحاولة. الروابط الخارجية بتفتح بمتصفح الجوال. زر الرجوع بيرجّع صفحة بالموقع.

## لكل زبون (4 خطوات)
1. أنشئ مستودع GitHub جديد (خاص) باسم الزبون، وارفع محتويات هالمجلد عليه.
2. عدّل ملف `app.config.json` فقط:
   - `appId`: معرّف فريد لكل تطبيق، أحرف إنكليزية صغيرة، مثلاً `com.zabon.menu`
   - `appName`: اسم التطبيق تحت الأيقونة
   - `url`: رابط الموقع، لازم يبدأ بـ `https://`
   - `themeColor`: لون التطبيق، مثلاً `#0F5C6E`
3. استبدل `resources/icon.png` (1024×1024) و`resources/splash.png` (2732×2732) بشعار الزبون.
4. بعد الرفع، GitHub Actions بيبني التطبيق لحاله (5 لـ10 دقايق). حمّل `app-debug.apk` من صفحة **Releases**، الإصدار `latest-debug`.

## حدود لازم تعرفها
- **أندرويد فقط**، ولا iOS.
- التطبيق بيعرض الموقع من الإنترنت، فبدون اتصال بيظهر شاشة "ما في اتصال".
- الملف الناتج **نسخة تجريبية (debug)** للتجربة والتسليم كـ APK. ما هو ملف جاهز للنشر على المتاجر.
- المتاجر ممكن ترفض تطبيق هو مجرد غلاف لموقع بدون ميزات إضافية. الزبون مسؤول عن ذلك عند النشر.
- ملف التوقيع `debug.keystore` مفتاح تجريبي معروف، مو للنشر.

## حالة الاختبار
فُحصت إضافة منصة أندرويد ومزامنة الإعدادات وتطبيق التوقيع محلياً، وفُحصت رسائل الأخطاء لقيم `app.config.json` الخاطئة. **ما انبنى APK ولا انجرّب على جهاز**، لأنه بيئة التجهيز ما فيها Android SDK. البناء الأول على GitHub هو الاختبار الفعلي، وإذا فشل ابعت سجل الخطأ (Log) من تبويب Actions.
